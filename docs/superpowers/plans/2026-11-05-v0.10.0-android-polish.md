# v0.10.0 Android polish — Implementation Plan

**Status:** Approved
**Date:** 2026-11-05

> Design spec: [2026-11-05-v0.10.0-android-polish-design.md](../specs/2026-11-05-v0.10.0-android-polish-design.md)
> Roadmap: [2026-10-23-v0.6.0-roadmap-design.md](../specs/2026-10-23-v0.6.0-roadmap-design.md)

## Global constraints

- Go 1.27.1, dependencies vendored; builds and tests must work with no network.
- Control protocol v1 stays byte-compatible; no `internal/ipc` envelope changes.
- Android: `minSdk 26`, `targetSdk 36`, `compileSdk 37.2` (`compileSdkMinor = 2`);
  no new Gradle dependency (D4).
- The engine stays OS-free; no new platform branches.
- Commit style `type: lowercase imperative summary`; one logical change per
  commit; every commit leaves the Go gate green.
- Never push, tag, or publish without an explicit request (D27).
- The Go gate is `make lint && make test && go test -race -count=1 ./... && make
  build && make build-arm64 && GOOS=windows GOARCH=amd64 go vet ./... && GOOS=windows
  GOARCH=amd64 go build ./... && GOOS=android GOARCH=arm64 go build ./...`.
- The Android gate is `make android-test`; the emulator suite is
  `make android-emulator-test` (AVD `kumiho-api36`, x86_64, booted).
- Every task below must leave `make android-test` green once it touches
  `android/`.

### T1 — Empty AAAA answers in the tunnel resolver (D16, D17, D32)

**Files**

- `internal/dns/dns.go`
- `internal/dns/dns_test.go`
- `internal/doctor/doctor.go`
- `internal/doctor/doctor_test.go`

**Changes**

1. In `internal/dns/dns.go`, extract the tail of `Server.HandleQuery` (message
   id, EDNS0 echo, UDP truncation) into:
   ```go
   func (s *Server) finishResponse(req, resp *mdns.Msg, overUDP bool) *mdns.Msg
   ```
   Every return path uses it.
2. After the one-question check, before `key := queryKey(q)`:
   ```go
   if q.Qtype == mdns.TypeAAAA {
       empty := new(mdns.Msg)
       empty.SetReply(req)
       empty.Rcode = mdns.RcodeSuccess
       s.logf(logging.Debug, "suppressed AAAA query for %s", q.Name)
       return s.finishResponse(req, empty, overUDP)
   }
   ```
   No cache read or write on this path.
3. After `s.resolve(...)` returns and before `s.cache.put`, for
   `q.Qtype == mdns.TypeANY`, replace `resp.Answer` with a fresh slice holding
   only non-`*mdns.AAAA` records. Do not mutate the backing array in place: the
   `Resolver` cache may still share the message.
4. In `internal/doctor/doctor.go`, add
   `const ipv6EnabledDetail = "IPv6 enabled; the tunnel answers AAAA empty and blackholes IPv6"`
   and return it from `checkIPv6` instead of the old "no AAAA stripping" text.
   `internal/doctor/doctor_test.go` gains `TestIPv6DetailDescribesAAAA` asserting
   the constant contains `AAAA` and not `no AAAA stripping` (the check runs
   Linux-only, so the constant is the testable unit).

**Tests to add (`internal/dns/dns_test.go`)**

- `TestAAAAIsEmptyNODATAAndNotCached`: a `Server` with a counting `Resolve`;
  an AAAA query returns `RcodeSuccess`, `len(Answer) == 0`, and `Resolve` is
  never called; the second identical query behaves the same.
- `TestANYDropsAAAA`: `Resolve` returns one A, one AAAA and one TXT record; the
  returned `Answer` has no AAAA and keeps A + TXT; a second query is served from
  the server cache with the same stripped shape and one resolver call.
- `TestAQueryIsUnaffected`: an A query still returns its A record (regression
  guard for the refactor).

**Verification**

```

```

Expected: all tests pass, gofmt/vet clean.

### T4 — Widget state reducer and quota in the shared snapshot (D7–D9, D15, D30)

**Files**

- `android/app/src/main/java/dev/benyamin/kumiho/vpn/TileState.kt`
- `android/app/src/main/java/dev/benyamin/kumiho/vpn/VpnStatusCache.kt`
- `android/app/src/main/java/dev/benyamin/kumiho/widget/WidgetState.kt` (new)
- `android/app/src/test/java/dev/benyamin/kumiho/widget/WidgetStateTest.kt` (new)

**Interfaces**

```kotlin
// vpn/TileState.kt
data class TileSnapshot(
    val state: VpnUiState,
    val location: String? = null,
    val proxyOnly: Boolean = false,
    val connectInFlight: Boolean = false,
    val quota: Quota? = null,        // engine Quota, null when not reported
)

// widget/WidgetState.kt
enum class WidgetSize { TOGGLE_1X1, STATUS_2X1 }
enum class WidgetLabel {
    NOT_CONNECTED, CONNECTED, CONNECTING, PROXY_ONLY, RECONNECTING, WAITING,
    SIGN_IN_REQUIRED, PERMISSION_NEEDED, UNAVAILABLE, ERROR,
}
sealed interface WidgetQuota {
    data object Hidden : WidgetQuota
    data object Unknown : WidgetQuota
    data class Percent(val value: Int) : WidgetQuota   // 0..100
}
data class WidgetPresentation(
    val active: Boolean,
    val label: WidgetLabel,
    val location: String?,      // uppercase country code; null for rec/blank
    val quota: WidgetQuota,
    val action: TileAction,
)
object WidgetState {
    fun reduce(snapshot: TileSnapshot?, consentGranted: Boolean): WidgetPresentation
}
```

**Changes**

1. `VpnStatusCache.update` sets `quota = state.status?.quota`.
2. `WidgetState.reduce` delegates truth, action and consent to
   `TileState.reduce(snapshot, consentGranted)`; it maps `TileSubtitle` to
   `WidgetLabel`, normalizes the location exactly like `TileState.location`
   (`rec`/blank → null), and computes quota:
   - visible states: `CONNECTED`, `RECONNECTING`, `WAITING`, `PROXY_ONLY`,
     `ERROR`;
   - `Percent(AccountState.quotaPercent(snapshot.quota))` when non-null,
     `Unknown` otherwise, `Hidden` for every other state.
3. Do not change `TileState.reduce` behavior; existing `TileStateTest` stays as
   is (quota defaults to null there).

**Tests (`WidgetStateTest.kt`)**

- Every `VpnUiState` maps to the expected label/action/active.
- `null` snapshot → `UNAVAILABLE`, action `OPEN_APP`.
- `OFF` with and without consent → `NOT_CONNECTED` vs `PERMISSION_NEEDED`.
- `CONNECTED` with `location = "de"` → `location == "DE"`; `"rec"` → `null`.
- Quota: both values → `Percent(25)`; missing limit or remaining → `Unknown`;
  `remaining = 0` → `Percent(0)`; `remaining > limit` → `Percent(100)`.
- `CONNECTING` → `Hidden`; `PROXY_ONLY` → quota visible and location null.
- `ERROR` with quota → visible; `NOT_SIGNED_IN` → `Hidden` + `OPEN_APP`.


**Interfaces**

```kotlin
object WidgetRefresh {
    fun request(context: Context)                                    // both providers, no-op when none
    fun render(context: Context, manager: AppWidgetManager,
                ids: IntArray, size: WidgetSize)
}
object WidgetActions {
    fun toggle(context: Context)     // disconnect when active, else connect
    fun openApp(context: Context)
}
class KumihoToggleWidgetProvider : AppWidgetProvider()   // onUpdate -> TOGGLE_1X1
class KumihoStatusWidgetProvider : AppWidgetProvider()   // onUpdate -> STATUS_2X1
class WidgetConnectActivity : ComponentActivity()         // transparent toggle target
```

**Changes**

1. `WidgetRefresh.request` gets `(application as KumihoApplication).container`,
   returns when `themeRepository.state.value` is not `PaletteState.Ready`, then
   renders every present id of both providers. `render` reads
   `VpnStatusCache.current()`, calls `WidgetState.reduce(snapshot,
   PermissionController.vpnPrepareIntent(context) == null)` and builds the
   `RemoteViews` for the given size.
2. 1×1 layout (`widget_toggle.xml`): `FrameLayout id/widget_root` (4 dp padding)
   with `ImageView id/widget_icon` 32 dp. Icon =
   `ic_widget_on`/`ic_widget_off`, tinted `colors.primary` when active and
   `colors.onSurface` when not; content description = the state word (reuse
   `tile_subtitle_*`, with `tile_subtitle_connected_location` when a location
   exists); whole root click → `WidgetConnectActivity`.
3. 2×1 layout (`widget_status.xml`): horizontal root with the same icon on the
   left and a vertical text column: `TextView id/widget_line1` (14 sp) and
   `TextView id/widget_line2` (12 sp). Line 1 = `WidgetLabel` string; line 2 =
   up to two segments joined by ` · `: the location and the quota
   (`account_row_quota_left` with the percent, or `account_row_quota_unknown`);
   `GONE` when both segments are absent. Icon click → `WidgetConnectActivity`;
   root/text click → `MainActivity`.
4. Colors: `setInt(id/widget_root, "setBackgroundColor",
   colors.surfaceContainer.toArgb())`, text `colors.onSurface.toArgb()`, icon
   as above. No raw hex in layouts; initial layouts use transparent/theme
   defaults and are only visible before the first palette-ready render (D13).
5. PendingIntents: `PendingIntent.getActivity` with distinct request codes
   (100 toggle, 101 open-app), `FLAG_IMMUTABLE or FLAG_UPDATE_CURRENT`.
6. `WidgetActions.toggle` reduces the current snapshot; `DISCONNECT` calls
   `coordinator.disconnect()`, `CONNECT` calls `coordinator.connect(ConnectRequest())`
   (via `WidgetConnectActivity` when consent is pending), `OPEN_APP` opens
   `MainActivity`, `NONE` does nothing. `WidgetConnectActivity` performs the
   no-consent action immediately (or shows `VpnService.prepare`, connects on
   `RESULT_OK`) and finishes in every branch.
   The activity is the click target for **every** toggle, not only consent
   prompts: this avoids background-activity/FGS start restrictions from a
   widget broadcast receiver while keeping D11's consent behavior. Provider
   receivers never start activities directly.
7. `WidgetConnectActivity` uses `@android:style/Theme.Translucent.NoTitleBar`,
   `exported=false`, `noHistory=true`, `excludeFromRecents=true`.
8. Manifest: two `<receiver android:exported="false">` entries with
   `APPWIDGET_UPDATE` intent filters and `android:name="android.appwidget.provider"`
   metadata pointing at the info XMLs. Info XMLs set `minWidth`/`minHeight`
   (40×40 dp toggle, 110×40 dp status), `targetCellWidth`/`targetCellHeight`
   (1×1 / 2×1), `resizeMode="none"`, `widgetCategory="home_screen"`,
   `updatePeriodMillis="0"`, `initialLayout`, `description`.
9. `VpnServiceCoordinator`'s existing collector: after
   `VpnStatusCache.update(snapshot)`, compare `tile.copy(connectInFlight =
   false)` (quota included) with the last value and call
   `WidgetRefresh.request(appContext)` on change; keep the tile comparison as
   `tile.copy(connectInFlight = false, quota = null)` so quota polls never wake
   the tile (D30).
10. `AppContainer.start()` collects `themeRepository.state` and calls
    `WidgetRefresh.request(appContext)` whenever it becomes `Ready` (theme or
    accent change re-renders both widgets).
11. New strings: `widget_toggle_label` "Kumiho toggle", `widget_status_label`
    "Kumiho status", `widget_toggle_description` "Connect or disconnect
    Kumiho", `widget_status_description` "Kumiho connection status". Reuse
    `tile_subtitle_*`, `account_row_quota_left`, `account_row_quota_unknown`.
12. Drawables: 24 dp vectors, `ic_widget_on` = filled 2×2 grid (reuse
    `ic_tile` path), `ic_widget_off` = outlined grid with a diagonal slash; both
    `#FF000000` fill, tinted at render.

## Risks + rollback

- **Widget delta from spec.** T5 routes every toggle through
  `WidgetConnectActivity` (the spec says the activity is the consent path).
  Reason: a widget broadcast receiver cannot reliably start an activity or a
  foreground service under background-start restrictions. Rollback: none
  needed; D11 is still honored, and the activity is invisible.
- **Palette gating.** Widgets render only after `ThemeRepository` is `Ready`;
  the launcher shows the initial layout for the brief load. Accepted in D13.
- **RemoteViews color APIs.** `setInt(..., "setBackgroundColor")` and
  `setColorFilter` are used on API 26+; corner radius comes from the host.
  Rollback: ship solid system-colored backgrounds if a host misbehaves.
- **Shared cache mutation.** ANY stripping must copy the answer slice; an
  in-place edit would corrupt the resolver cache. Covered by
  `TestANYDropsAAAA`.
- **Default change ripples.** Any missed `standard` default assertion fails
  `go test ./...`; rollback is restoring `DefaultConfig`.
- **Emulator suite availability.** It needs the booted AVD; if it cannot run,
  the release task must not claim D24 complete.
