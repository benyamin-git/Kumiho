# v0.11.0 Android design language — Implementation Plan

**Status:** Draft
**Date:** 2026-11-05

> Spec: [2026-11-05-v0.11.0-android-design-language-design.md](../specs/2026-11-05-v0.11.0-android-design-language-design.md) (approved).

This plan is the argument from the spec. It carries every decision an
implementer cannot make: exact files, interfaces, verification commands and
commit boundaries. No estimates.

## Global constraints

Copied from the spec and the repository rules:

- **Platform:** Android phone only. No file under `ui/tv/`, `android/app/src/main/res/values-*` TV
  assets, `TvAppShell`, or the TV connected suite may change except where a
  shared token is consumed. TV adoption is a later, separate plan.
- **Versions:** Go 1.27.1; Kotlin 2.4.21; AGP 9.4.1; Compose BOM 2026.09.00;
  minSdk 26; targetSdk 36; compileSdk 37.2; JDK 17 at `~/Android/jdk-17`
  (`source scripts/android-env.sh`).
- **Dependencies:** none added. Charts use `androidx.compose.foundation.Canvas`,
  animation uses `androidx.compose.animation` (already on the classpath via
  Material 3).
- **Palette roles:** exactly `data-line`, `data-fill`, `data-grid`, `glow`.
  `data-line = primary`; `data-fill = primary at 0.18 over background`;
  `data-grid = outline at 0.32 over background`; `glow = primary at 0.16 over
  background`. All four are opaque `#rrggbb`, pre-composited on **background**;
  charts and the glow must sit on the page background, never on a raised
  `surface-container` fill.
- **Copy:** every new user-visible string goes into
  `android/app/src/main/res/values/strings.xml`, English only; translation is
  v0.13.0.
- **Motion:** one expressive spring for the arc, a 6 s glow cycle at low alpha,
  150–200 ms phase fades, one connect pulse and one haptic. All of it snaps or
  settles under reduced motion. The glow never runs while the app is not
  resumed.
- **Accessibility floor:** 4.5:1 body contrast in Light/Dark/OLED, 48 dp touch
  targets, meaning never colour-only, every new control labelled, charts
  summarised in text with the exact numbers rendered.
- **No engine, protocol, settings, migration or persistence change.** UX actions
  are composed from existing commands (`connect`, `disconnect`,
  `select_location`).
- **Service safety:** never restart `kumiho.service` or the emulator from this
  thread. The user has explicitly approved Gradle, emulator and connected-suite
  runs in this session (spec D37); reuse the already-running `emulator-5554`
  and never run two Gradle invocations concurrently.
- **Commits:** one logical change per commit; subject
  `type: lowercase imperative summary`; every commit leaves its gate green.
  Never tag or push without the explicit release instruction in T19.

**Interface**

```go
// Appended to cssOrder after "warning", in this order:
// "data-line", "data-fill", "data-grid", "glow".

const (
	dataFillAlpha = 0.18
	dataGridAlpha = 0.32
	glowAlpha     = 0.16
)

// compositeOver returns fg painted at alpha over bg as #rrggbb.
func compositeOver(fg, bg string, alpha float64) string

// dataRoles fills the four data roles in v. It is called at the end of values().
func dataRoles(v map[string]string)
```

`values()` ends with:

```go
v["data-line"] = v["primary"]
v["data-fill"] = compositeOver(v["primary"], v["background"], dataFillAlpha)
v["data-grid"] = compositeOver(n.outline, v["background"], dataGridAlpha)
v["glow"] = compositeOver(v["primary"], v["background"], glowAlpha)
```

`compositeOver` parses both hexes, blends each sRGB channel with
`round(fg*a + bg*(1-a))`, and formats `#%02x%02x%02x`.

**Fixture regeneration:** add `TestWritePaletteFixture` to
`mobile/palette_test.go`, skipped unless `KUMIHO_UPDATE_PALETTE_FIXTURE=1`. It

the JSON, and writes `../android/app/src/test/resources/palette.json` in the
existing shape (`_comment`, `light`, `dark`, `oled`, each an object of accent →
role map). Update the `_comment` to say 29 roles and to name the env var as the
regeneration path. Add the four role names to the existing required-key loop.

## T4 — Rate buffer

**Files**

- `android/app/src/main/java/dev/benyamin/kumiho/ui/components/RateBuffer.kt`
- `android/app/src/test/java/dev/benyamin/kumiho/ui/components/RateBufferTest.kt`

**Interface**

```kotlin
/** One engine sample: the wall clock and the two byte rates. */
data class RateSample(val atMillis: Long, val down: Double, val up: Double)

/**
 * The last [capacity] samples of a live session. A gap wider than
 * [maxGapMillis] clears the buffer so the trace never draws a straight line
 * across a pause.
 */
class RateBuffer(
    private val capacity: Int = 30,
    private val maxGapMillis: Long = 5_000,
) {
    fun push(rates: ByteRates?, nowMillis: Long): Boolean
    fun snapshot(): List<RateSample>
    fun clear()
    val size: Int
}
```

Rules: null rates return `false` and change nothing; negative or non-finite
rates clamp to `0.0`; a sample older than the last one replaces the buffer
(clock going backwards); a gap `> maxGapMillis` clears first; `snapshot()`
returns an immutable copy.

**Tests:** capacity trimming, gap reset, null no-op, clamp, backwards clock,
snapshot isolation, `size` after clear.

**Verification**

`cd android && ./gradlew --no-daemon -PkumihoEmulator=true :app:testDebugUnitTest --tests '*RateBufferTest*'`
— expect pass.

## T5 — Gauge component

**Files**

- `android/app/src/main/java/dev/benyamin/kumiho/ui/components/GaugeGeometry.kt`
- `android/app/src/main/java/dev/benyamin/kumiho/ui/components/Gauge.kt`
- `android/app/src/test/java/dev/benyamin/kumiho/ui/components/GaugeGeometryTest.kt`
- `android/app/src/main/res/values/strings.xml` (descriptions)

**Interface**

```kotlin
object GaugeGeometry {
    const val START_DEGREES = -90f
    const val WINDOW_MILLIS = 60_000L
    const val ARC_STROKE_DP = 8f
    const val TRACE_BAND_DP = 18f

    fun quotaSweep(fraction: Float?): Float            // null -> 0, clamped 0..360
    fun sampleSweep(atMillis: Long, nowMillis: Long): Float // 0..360, older than window -> 0
    fun radiusFraction(value: Double, max: Double): Float   // 0..1, max <= 0 -> 0
}

@Composable
fun KumihoGauge(
    stateLabel: String,
    connected: Boolean,
    quotaFraction: Float?,
    samples: List<RateSample>,
    onToggle: () -> Unit,
    modifier: Modifier = Modifier,
    busy: Boolean = false,
    enabled: Boolean = true,
    size: Dp = 248.dp,
)
```

Drawing order:

1. Glow: a radial brush from `glow` to transparent, radius `size/2`, drawn only
   when `connected` and motion is on; a static low-alpha ring otherwise.
2. Track: 8 dp arc at `outlineVariant`, full 360°.
3. Quota arc: 8 dp arc from `START_DEGREES`, `quotaSweep(fraction)`, colour
   `primary`; empty when the fraction is null.
4. State sweep: while `busy`, a 90° `data-line` arc rotating; static 90° at the
   top under reduced motion.
5. Trace: inside the arc, two concentric bands. Download is a filled band
   (`data-fill`) between its radius and the band floor; upload is a 2 dp line
   (`data-line`) on the inner band. No samples → nothing.
6. Centre: the existing `ic_power` glyph on a 96 dp `primary`/`primaryContainer`
   circle (the touch target), or `CircularProgressIndicator` when busy.

Semantics: `contentDescription = stringResource(R.string.gauge_description, stateLabel)`,
`stateDescription = stateLabel`, `role = Role.Button`, `onClick` only when
`enabled && !busy`. The arc and trace are decorative; they never carry the only
copy of a fact.

**Tests:** `quotaSweep(null) == 0`, clamps at 0/1, a sample at `now` is at 0°,
at `now - 30 s` at 180°, older than 60 s is 0, `radiusFraction` clamps and
handles `max = 0`.

**Verification**

1. Focused unit test — expect pass.
2. `make android-test` — expect pass.
3. The existing `DashboardScreenshotsTest` still compiles (tags preserved).

**Commit:** `feat: draw the connection gauge`

**Interface**

```kotlin
interface DiagnosticsGateway {
    suspend fun facts(): AndroidFacts
    suspend fun doctor(facts: AndroidFacts): DoctorReport
    suspend fun resetState()
    fun status(): StateFlow<EngineStatus?>
    suspend fun cachedLatency(): Map<String, CachedPing>
}

data class LatencyBar(val host: String, val rttMs: Double)

enum class DiagnosticsChartNote { NO_SESSION, NO_CACHE, LATENCY_UNAVAILABLE }

data class DiagnosticsUiState(
    // existing fields …
    val trace: List<RateSample> = emptyList(),
    val latency: List<LatencyBar> = emptyList(),
    val chartNote: DiagnosticsChartNote? = null,
)
```

`AndroidDiagnosticsGateway` implements `status()` from
`coordinator.awaitEngine().status` and `cachedLatency()` from
`engine.locationsResult(refresh = false).latency`, filtering finite `rttMs`,
sorting ascending, and taking the first 12. It never calls `ping`.

`DiagnosticsViewModel` collects `gateway.status()` into a `RateBuffer` while the
VM lives, and calls `cachedLatency()` during `load()`. A latency failure keeps
the doctor report and sets `LATENCY_UNAVAILABLE`; no session sets `NO_SESSION`;
an empty map sets `NO_CACHE`.

`ThroughputChart(samples, modifier)`: full-width 120 dp Canvas chart, download
area at `data-fill`, upload line at `data-line`, a `data-grid` baseline, axis
labels in `bodySmall` tabular, and a text summary row
`Down X/s · Up Y/s · peak Z/s`.

`LatencyChart(bars, modifier)`: horizontal bars `data-line`, host label
`bodySmall`, RTT right-aligned tabular; empty → the note line, never an empty
axis.

**Asset generation (exact)**

```bash
mkdir -p /tmp/opencode/wordmark
curl -sL -o /tmp/opencode/wordmark/Roboto-SemiBold.ttf \
  https://fonts.gstatic.com/s/roboto/v51/KFOMCnqEu92Fr1ME7kSn66aGLdTylUAMQXC89YmC2DPNWuYaalmUiA8.ttf
sha256sum /tmp/opencode/wordmark/Roboto-SemiBold.ttf
# 868599499d20ee12589f2b7a314443d5bbe86d88e95eb2bf89b6f2fb9cb0e3c5
source scripts/android-env.sh
java scripts/GenerateWordmark.java /tmp/opencode/wordmark/Roboto-SemiBold.ttf Kumiho 0.06 \
  > android/app/src/main/res/drawable/ic_wordmark.xml
```

`GenerateWordmark.java` is a single-file Java 17 program: load the TTF with
`Font.createFont`, build a `GlyphVector` at 100 px, apply `tracking × size` to
every glyph position, take `getOutline()`, walk the `PathIterator`, and print an
Android `<vector>` with `android:width="128dp"`, `android:height="28dp"`,
`android:viewportWidth/Height` from the outline bounds, and
`android:fillColor="@color/kumiho_on_surface"`. Coordinates are emitted with two
decimals, y flipped from font space to viewport space. The file header records
the font name, URL, SHA-256 and the Apache-2.0 licence.

Themes (both `values` and `values-night` `Theme.Kumiho`):

```xml
<item name="windowSplashScreenBrandingImage">@drawable/ic_wordmark</item>
```

On API 26–30 the compat splash ignores the attribute; that is accepted and
documented. `NOTICE` gains: Roboto SemiBold outlines, Apache License 2.0,
Copyright The Android Open Source Project.

## T15 — Switch location while connected

**Files**

- `ui/locations/LocationsViewModel.kt`
- `ui/locations/LocationsScreen.kt`
- `ui/locations/SwitchLocation.kt` (new: the pure choreography)
- `ui/locations/LocationsState.kt` (if the state lives there)
- `android/app/src/test/java/dev/benyamin/kumiho/ui/locations/SwitchLocationTest.kt`
- `strings.xml`

**Interface**

```kotlin
interface LocationsGateway {
    // existing methods …
    fun service(): StateFlow<ServiceState>
    suspend fun status(): EngineStatus
    suspend fun disconnect()
    suspend fun connect()
}

sealed interface SwitchStep {
    data object Idle : SwitchStep
    data object Disconnecting : SwitchStep
    data class Connecting(val target: String) : SwitchStep
    data class Failed(val message: String) : SwitchStep
}

data class SwitchTarget(
    val countryCode: String,
    val cityCode: String?,
    val server: String,
    val label: String,
)

class SwitchLocation(
    private val gateway: LocationsGateway,
    private val timeoutMillis: Long = 15_000,
    private val pollMillis: Long = 250,
) {
    suspend fun run(target: SwitchTarget, onStep: (SwitchStep) -> Unit): Result<Unit>
}
```

Sequence: `onStep(Disconnecting)` → `disconnect()` → poll `status().state` until
it is not a connected family (`connected`, `proxy_only`, `reconnecting`,
`waiting`) or the timeout expires → `selectLocation(countryCode, cityCode,
server)` → `onStep(Connecting(label))` → `connect()` → `Result.success`.

Failure: return `Result.failure` with the engine's message; the caller sets
`SwitchStep.Failed`. A timeout message is "The session did not stop in time."
No retry loop inside `run`; the dialog's **Retry** calls it again.

Locations state gains `sessionActive: Boolean`, `lockdown: Boolean` and
`pending: SwitchTarget?`, sourced by collecting `gateway.service()`.

UI: selecting a row while `sessionActive` sets `pending` and opens an
`AlertDialog` titled **Switch location?** with the target, the sentence that the
current session ends, a **Lockdown is on** warning line when `lockdown`, and
**Switch**/**Cancel**. While running the dialog shows the step; **Retry** on
failure; **Close** leaves the app honestly disconnected. Selecting while not
connected keeps today's behaviour (select for next connect) with no dialog.

Tests (fake gateway, `runTest`): happy path order is exactly
`disconnect → status… → select → connect`; failure at each step; timeout;
lockdown does not change the sequence; `connect` is never called before the
status leaves the connected family.

2. `make android-emulator-test` — the existing Locations suite must pass with
   the new dialog.
3. Manual: connect on the emulator, tap another location, confirm the dialog,

## Risks + rollback

| Risk | Mitigation |
| --- | --- |
| A palette role is wrong in one theme/accent | T1 asserts all 18 pairs; T17 reviews Light, Dark, OLED and one accent on the device |
| The gauge or glow hurts frame time on low-end hardware | No allocation in draw, one buffer, glow only while resumed, reduced-motion path; the emulator review catches obvious jank |
| Pre-composited roles are used on a raised surface by mistake | The rule is in `docs/design.md`; charts sit on `background`, cards do not host charts |
| Switch-location leaves a stale session if disconnect times out | 15 s poll bound, honest failure state, Retry; no connect is issued before the status leaves the connected family |
| The splash attr is ignored on older Android | Accepted and documented; no in-app frame is added |
| Gradle/emulator runs disturb the service | Reuse the running emulator, never restart the service, one Gradle at a time (D37) |
